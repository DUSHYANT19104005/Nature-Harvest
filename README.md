Nature Harvest Website

Nature Harvest is a responsive agricultural products website created to showcase products and provide an easy way for buyers to send enquiries.

Pages

* Home
* Products
* Contact / Request a Quote

Features

* Responsive design for mobile, tablet and desktop
* Mobile hamburger navigation
* Product cards
* FAQ section
* Contact and enquiry form
* Basic form validation
* WhatsApp contact option
* Basic SEO and accessibility improvements

Technologies Used

* HTML5
* CSS3
* JavaScript
* VS Code
